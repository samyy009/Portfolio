# Portfolio

A modern, animated personal portfolio built with **React**, **Vite**, and **Framer Motion**.

## Features
- Hero section with animated avatar and smooth scrolling.
- Tabbed **Achievements** section showcasing milestones, certificates, and group photos.
- Projects gallery with light‑box modal and responsive grid.
- Glass‑morphism UI, gradients, and interactive hover effects.
- Dark‑mode‑friendly design and responsive layout for mobile, tablet, and desktop.

## Tech Stack
- **React** (functional components, hooks)
- **Vite** for fast dev server and production build
- **Framer Motion** for animations
- **Tailwind CSS** for utility‑first styling
- **GitHub Pages / Netlify** ready for deployment

## Getting Started
```bash
# Clone the repo
git clone https://github.com/samyy009/Portfolio.git
cd Portfolio

# Install dependencies
npm ci

# Run development server
npm run dev
```

Visit `http://localhost:5173` to see the live preview.

## Build for Production
```bash
npm run build   # generates the ./dist folder
```

Deploy the `dist` folder to any static‑hosting service (e.g., GitHub Pages, Netlify, Vercel).
